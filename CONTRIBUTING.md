# Contributing

## Development

```bash
bundle install
bundle exec rspec
bundle exec rubocop lib spec
```

## Pull requests

1. Fork `Trigv/trigv-ruby` and branch from `main`
2. Run RSpec and RuboCop
3. Update `CHANGELOG.md` for user-visible changes

## API contract

Match [Trigv OpenAPI](https://api.trigv.com/openapi.yaml).

## Security

Never commit API keys.
